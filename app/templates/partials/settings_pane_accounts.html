Google OAuth setup

One-time setup. Gmail accounts are only read — mail never leaves your machine.

1
Create a Google Cloud project

Open console.cloud.google.com and create a project (any name).

2
Enable the Gmail API

Go to APIs & Services → Library, search Gmail API, click Enable.

3
Configure the consent screen

User type External. Add scope gmail.readonly and your Gmail address under Test Users.

4
Create an OAuth client

Credentials → Create credentials → OAuth client ID, application type Desktop app.

5
Download credentials.json

Download the client secret and upload it here, or save it as ~/.local/share/InboxZen/credentials.json. Then click Connect.
